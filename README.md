# Guess the Fake

A fast, replayable browser game built for [Pollinations quest #15725](https://pollinations.ai).

Two images appear side by side. One is a real photograph, one was generated by AI. You have
ten seconds per round to spot the fake. Answer quickly and keep a streak going to score more.

## Gameplay

- **10 rounds.** Every round pairs one real photograph with one AI-generated image.
- **Countdown timer.** Each round gives you 10 seconds, shown as a number and a progress bar.
  Run out of time and the round is lost and your streak resets.
- **Scoring.** 100 base points for a correct answer, plus up to 50 bonus points scaled by how
  much time was left, all multiplied by 20% per consecutive correct answer.
- **Results.** Score, correct count out of 10, accuracy, longest streak, and a rank from
  *Novice Observer* up to *Master Detector*, with a share button.
- **Best score** is stored in `localStorage` and shown on the start and results screens.

### Controls

| Action | Keyboard | Pointer |
| --- | --- | --- |
| Start the game | `Enter` / `Space` | Start game button |
| Pick the AI image | `1` or `←` for left, `2` or `→` for right | Tap/click an image |
| Continue | `Enter` | Next round button |
| Play again | `Enter` | Play again button |

The round result also advances automatically after a short pause. Motion is reduced when the
operating system requests `prefers-reduced-motion`, and every outcome is announced through an
ARIA live region for screen-reader users.

## Stack

- Next.js 15 (App Router) + TypeScript
- Tailwind CSS (dark UI, responsive from 360px phones up to desktop)
- Vitest for unit tests of the pure game logic
- **Fully static:** `output: 'export'` with `images.unoptimized`, so the build produces plain
  HTML/CSS/JS. There is no server runtime, no API route, no secret, and no runtime environment
  variable. All 10 images are committed, so the game plays entirely offline.

## Getting started


bash
npm install
npm run dev      # http://localhost:3000
npm test         # unit tests (Vitest)
npm run build    # static export into ./out
npm start        # serve the exported ./out directory



## Deploying to Vercel

This project is a static export and works on the Vercel free tier.

1. Import the repository at [vercel.com/new](https://vercel.com/new).
2. Framework preset: **Next.js**.
3. Build command: `npm run build`.
4. Output directory: `out`.
5. Deploy. No environment variables are required.

The same `out/` directory can be hosted on any static host (Cloudflare Pages, GitHub Pages,
S3, Netlify) without further configuration.

## Project layout



src/app/layout.tsx          Root layout and metadata
src/app/page.tsx            Entry page — renders the game
src/components/Game.tsx     Game UI: preload, rounds, timer, results, share
src/components/Providers.tsx  Reduced-motion and live-region providers
src/lib/game-logic.ts       Pure, deterministic game logic (seeded rounds, scoring)
src/lib/game-logic.test.ts  Unit tests for the logic above
public/images/              The 10 committed images (5 real, 5 AI)
public/images/CREDITS.md    Per-image source and licence details



The game logic is deliberately framework-free: rounds are produced from a seeded Fisher-Yates
shuffle, so a given seed always reproduces the same game. That makes the scoring, timeout and
round-progression behaviour unit-testable without a DOM.
