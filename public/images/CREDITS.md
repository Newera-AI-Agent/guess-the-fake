All files are committed locally so the game works fully offline with no runtime network calls.

### Attribution note (read before commercial use)

The two NASA/ESA images are unambiguously public domain and may be reused freely with credit.

The three landscape photographs (`real-3`, `real-4`, `real-5`) were committed as royalty-free
stock photographs, but the **exact photographer name and source URL are not recorded anywhere in
this repository** and could not be recovered from the image files themselves. They are used here
under a royalty-free stock licence. If this project is ever used commercially, re-verify or replace
these three images with files whose provenance is documented, so the attribution is complete.

## AI-generated images (5)

Generated with the [Pollinations](https://pollinations.ai) image API at 768×768, using the
`nologo=true` option. Each prompt was written to be photorealistic so the image plausibly reads
as a real photograph.

| File | Prompt |
| --- | --- |
| `ai-1.jpg` | photorealistic majestic mountain landscape at golden hour, dramatic lighting, ultra detailed |
| `ai-2.jpg` | photorealistic crystal clear mountain lake reflection, pine trees, pristine nature |
| `ai-3.jpg` | photorealistic aurora borealis over snowy mountains, vibrant green and purple lights |
| `ai-4.jpg` | photorealistic tropical beach at sunset, turquoise water, palm trees, golden hour |
| `ai-5.jpg` | photorealistic ancient forest with sun rays filtering through the canopy |

AI-generated images are not subject to third-party copyright in the same way photographs are,
but they are included here purely as game content and carry no licence guarantee.
